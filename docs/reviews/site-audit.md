## Implementation integrity: ผ่าน

เว็บมีระบบดีไซน์ของตัวเอง (Teal & Gold on paper) มี token เป็น CSS custom property หน้า `/styleguide` แสดงทุก component และ DESIGN.md ระบุอัตราส่วนคอนทราสต์ของแต่ละสี ไม่ได้เป็นเทมเพลตที่ใช้แทนกันได้กับผลิตภัณฑ์อื่น

ที่ detector เตือนมี 2 อย่างในซอร์ส (แถบสีข้างการ์ด และพื้นหลังลายตาราง) และอีกไม่กี่อย่างในหน้าที่เรนเดอร์จริง ทั้งหมดเป็นระดับเตือนเล็กน้อย ดูรายละเอียดในข้อ F11

## ที่ทำได้ดี

### ผ่าน Accessibility

- มี skip link และกรอบโฟกัส 3px ที่เห็นชัดทุกตัวที่ทดสอบด้วย Tab
- รูปทุกใบมี `alt`, `lang="en"` และ viewport ถูกต้อง
- ช่องฟอร์มมี label ครบ (axe ไม่พบปัญหา label)
- รองรับ `prefers-reduced-motion` 39 จุดในโค้ด

### ผ่าน งานวิศวกรรม

- 50 หน้าตอบ 200 ไม่มี console error
- ไม่มีหน้าไหนเลื่อนซ้ายขวาที่ 390px นอกจากหน้าทดสอบภายใน
- รูปที่อยู่ใต้หน้าจอแรกใช้ lazy loading ครบ
- มี PWA manifest, service worker และ JSON-LD
- ฟอร์ม API ตอบ 422 พร้อมบอกช่องที่ผิด ไม่มี secret ใน repo
