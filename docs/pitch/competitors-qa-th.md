# เทียบคู่แข่ง: ฉบับขยายสำหรับตอบคำถามกรรมการ

ตัวเลขทั้งหมดมาจากเอกสารวิจัยของทีม (ตรวจ 23–24 ต.ค. 2026) ก่อนขึ้นพูดให้เปิด nomads.com/pricing และ Nomad Citizen FAQ เช็กราคาอีกรอบ

**ระวัง:** ตารางในข้อความที่ใช้ซ้อม (Nomad List + iVisa) ไม่ตรงกับไฟล์ `submission-th.md` และ `competitors-th.html` ซึ่งใช้ Nomad List + Plumia และให้ iVisa เป็นตัวสำรอง ให้ยึดชุดที่ส่งกรรมการไปจริง

## 3 จุดที่ต้องแก้ในตารางสั้น

1. **"SafetyWing Nomad Border Pass ราคา 400–600 USD/เดือน" ไม่ตรง** ราคานี้เป็นของสมาชิก **Plumia Nomad Citizen** ทั้งแพ็กเกจ ซึ่ง SafetyWing ขาย ส่วน Nomad Border Pass เป็นบริการช่วยเรื่องวีซ่าที่รวมอยู่ในนั้น
2. **FAQ ของ Nomad List ไม่ได้ยอมรับว่าข้อมูล "ไม่อัปเดต"** แต่ยอมรับว่ามีข้อมูลบางจุดที่ไม่แม่นยำ ให้พูดว่า "ไม่แม่นยำ"
3. **อย่าพูดว่า iVisa "ไม่โปร่งใส"** เพราะมาจากรีวิวผู้ใช้ ให้พูดว่า "คิดค่าบริการเพิ่มจากค่าธรรมเนียมรัฐ"

## คำถามที่น่าจะโดน

**Nomad List ใหญ่มาก ทำไมคนต้องใช้เรา?**
เขากว้าง เราลึก เขาดูเมืองทั่วโลก แต่เรื่องวีซ่าเป็นโน้ตของผู้ใช้ ไม่มีแหล่งและวันที่ เราทำไทยที่เดียว ทุกกฎมีลิงก์ทางการ และหลังเข้าไทยมีเตือนรายงานตัว 90 วัน วันวีซ่าหมด และนับ 180 วันภาษี

**ถ้า iVisa เพิ่ม DTV ล่ะ?**
iVisa จบที่การยื่นเอกสารก่อนเดินทาง ของเราอยู่กับผู้ใช้ทั้งช่วงที่อยู่ไทย ยื่น 90 วันช้าปรับ ฿2,000 ครั้งเดียวเท่ากับ Pro ราว 7 เดือน

**SafetyWing เงินเยอะ ลอกได้ไหม?**
เขาขาย $400–600 ให้คนรายได้สูง ลงมาที่ $8 จะกินสินค้าตัวเอง และเราเป็น affiliate ขายประกันให้เขาได้ (ราว 10% ต่อเนื่อง อ้างจากแหล่งบุคคลที่สาม)

**เอเจนต์วีซ่าไทยไม่ใช่คู่แข่งเหรอ?**
เป็นลูกค้า B2B เขาคิด ฿3,000–10,000 ต่อเคส บางเจ้าถึง ฿55,000 เราส่งลูกค้าที่คัดแล้วให้ เอเจนต์ต้องผ่านการตรวจตัวตนและทะเบียนธุรกิจก่อน ฐานข้อมูลไม่ยอมให้อนุมัติถ้ายังไม่ตรวจ

**อะไรลอกยาก?**
ความสดของข้อมูลไทยที่มีวันที่ตรวจ เครือข่าย buddy และเอเจนต์ที่ตรวจแล้ว และความเป็นกลาง เพราะเราไม่รับยื่นวีซ่าเอง

**ถ้าข้อมูลเราผิดล่ะ?**
ทุกหน้าบอกแหล่งและวันที่ตรวจ มีคำเตือนให้ยืนยันกับหน่วยงาน และข้อไหนยืนยันไม่ได้เราเอาออก เช่น ข้อมูลลงทะเบียน SIM ที่เปิดแหล่งทางการไม่ได้
