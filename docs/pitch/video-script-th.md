# สคริปต์วิดีโอเดโม 2 นาที: Yoo Yaao

> ไฟล์ที่ได้: `docs/pitch/yoo-yaao-demo-2min.mp4` (1920×1080, 30fps, H.264 + AAC, **1:49**)
> เสียงพากย์ไทยจาก macOS `say -v Kanya -r 185` (ไม่มีเสียง Thai แบบ premium/enhanced ในเครื่อง) · ไม่มีเพลงประกอบ
> ภาพเป็นแอปภาษาอังกฤษ บันทึกจาก `http://localhost:4321` ในโหมดเดโม (ไม่ล็อกอิน, ไม่มีการเก็บเงินจริง)
> สร้างใหม่ได้จาก `video/`: `npm run record` (อัดคลิป, ต้องเปิด dev server) → `npm run voice` → `npm run render`
> ข้อความพากย์และแคปชันแก้ที่ `video/src/script.json` ที่เดียว แล้วรัน `npm run voice` กับ `npm run render` ใหม่

## หมายเหตุ
- ตัวเลขในฉาก problem มาจากสคริปต์เดิมและ `docs/business-model.md`: visa-free 60 → 30 วัน (15 ก.ย. 2026), ค่าวีซ่าทางการ ฿10,000 เทียบเอเจนต์ ฿50,000+, ค่าปรับรายงานตัว 90 วันช้า ฿2,000 (immigration.go.th)
- ทุกหน้าที่ถ่ายเป็นโหมดเดโมและขึ้นป้าย "Demo view — sample data" หรือ "Demo mode: this is not a real payment" ให้เห็นบนจอ
- วิดีโอวนบนเว็บ (`app/public/media/demo.webm`, ไม่มีเสียง, 52 วินาที) ใช้ฉาก home, finder, buddy, business, admin และแสดงเฉพาะคีย์เวิร์ดภาษาอังกฤษ
