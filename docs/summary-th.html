1. ไอเดียใน 1 ย่อหน้า

เว็บแอป (PWA ติดตั้งบนมือถือได้) ภาษาอังกฤษ สำหรับ digital nomad และชาวต่างชาติที่อยากอยู่ไทยหลายเดือน ผู้ใช้กรอกสัญชาติ ประเทศที่อาศัย อายุ รายได้ และระยะเวลาที่อยากอยู่ แอปจะจัดอันดับวีซ่าที่เหมาะสม (DTV, LTR, Privilege, Visa-exempt, Retirement) พร้อมเหตุผล checklist เอกสาร และลิงก์แหล่งทางการที่ระบุวันที่ตรวจล่าสุดทุกข้อ เมื่อเข้าไทยแล้วมีเครื่องมือเตือนรายงานตัว 90 วัน นับวันวีซ่าหมด และนับ 180 วันเพื่อดูสถานะภาษี มีข้อมูลเมือง (กรุงเทพ เชียงใหม่ ภูเก็ต) และตลาด Local Buddies ที่ให้คนท้องถิ่นรับจ้างช่วยเรื่องจริงในชีวิตประจำวัน

ข้อจำกัด 3 ข้อ

  • เวลา: มีเวลาราว 2 วัน จึงทำเฉพาะประเทศไทยก่อน (วีซ่า 5 แบบ + 3 เมือง) ส่วนประเทศอื่นใน SEA ไว้เฟสถัดไป
  • งบ: ราว 0–66 USD/เดือน ใช้ Supabase, Vercel และข้อมูลเปิด ไม่ใช้ API ราคาแพง
  • ข้อมูลและกฎหมาย: กฎวีซ่าเปลี่ยนบ่อย จึงต้องตรวจกับแหล่งทางการเป็นรอบๆ และแอปให้ "ข้อมูล" เท่านั้น ไม่ยื่นวีซ่าแทนผู้ใช้ (เป็นงานที่มีกฎหมายควบคุม) ใช้วิธีส่งต่อให้เอเจนต์ที่มีใบอนุญาต

2. กลุ่มเป้าหมายและปัญหา

ใครปัญหาที่เจอ
Digital nomad / remote worker ชาวตะวันตก ชาวอินเดีย (โต +16–18% ในปี 2025) ผู้ถือ DTV 1) ไม่รู้ว่าวีซ่าตัวไหนเหมาะกับตัวเอง (เงื่อนไขขึ้นกับสัญชาติและประเทศที่ยื่น)
2) ข้อมูลกระจัดกระจาย บล็อกขัดกันเอง กฎเปลี่ยนบ่อย เช่น ฟรีวีซ่าลดจาก 60 เหลือ 30 วัน มีผล 15 ก.ย. 2569
3) ใช้ชีวิตหลังเข้าไทยยาก: ธนาคารไม่ให้ผู้ถือ DTV เปิดบัญชี ลืมรายงานตัว 90 วัน/TM30 และสับสนเรื่องภาษี 180 วัน
ผู้เกี่ยวข้อง: ททท. / ตม.อยากได้นักท่องเที่ยวระยะยาวที่ใช้จ่ายสูงและทำตามกฎหมาย

คู่แข่งข้อดีข้อเสียเราต่างอย่างไร
Nomad List (nomads.com)ข้อมูลเมืองทั่วโลก community ใหญ่ข้อมูลวีซ่า SEA เป็นโน้ตที่ผู้ใช้เขียนกันเองและไม่อัปเดต ไม่เจาะไทยเจาะไทย ทุกกฎมีแหล่งทางการและวันที่ เทียบวีซ่าตามสัญชาติ

5. Business Model (B2C · B2B · C2C)

กลุ่มแหล่งรายได้ราคา
B2CStay Pro: ระบบเตือน + tracker + alert เมื่อกฎเปลี่ยน$8/เดือน หรือ $59/ปี (ถูกกว่า 38%)
B2CAffiliate ประกัน (SafetyWing ~10% recurring, Genki 5–10%) และ eSIM (Airalo 10%)ค่าคอมมิชชัน
B2BFeatured listing ของ coworking/coliving/คอนโด$49/เดือน (founding partner)
B2Bส่ง lead ให้เอเจนต์/ทนายที่มีใบอนุญาต หรือแพ็กเกจ Verified Agent~$45/lead หรือ $199/เดือน
C2Cตลาด Local Buddies (session 60 นาที)$25–60 แพลตฟอร์มหัก 20%

ตัวเลขสำคัญ (model ไม่ใช่การพยากรณ์)

  • Base case เดือนที่ 12: รายได้ราว $1,890/เดือน (≈ ฿62,500) · สัดส่วน B2C 48% · B2B 45% · C2C 7%
  • คุ้มทุนรายเดือนตั้งแต่เดือนที่ 7 และทุนสะสมคืนในเดือนที่ 10 (ยังไม่รวมค่าแรงผู้ก่อตั้ง)
  • ช่วงผลลัพธ์: conservative ราว $550/เดือน · optimistic ราว $5,470/เดือน
  • ต้นทุนโครงสร้างพื้นฐาน $21–66/เดือน · Pro ARPU $7.08 · LTV ~$80 · CAC ~$35 · อัตราแปลงเป็น Pro 2–3%
  • รายได้จาก affiliate มีแค่ราว 21% จึงไม่ต้องพึ่งแพลตฟอร์มอื่นมาก (Booking.com เคยตัด affiliate รายเล็กกะทันหันในปี 2025)

6. ผลกระทบด้านการท่องเที่ยว (คะแนนพิเศษ)

ปี 2568 ไทยมีนักท่องเที่ยวต่างชาติ 32.97 ล้านคน (ลดลง 7.23%) สร้างรายได้ราว ฿1.53 ล้านล้าน คิดเป็นราว ฿47,000 ต่อการเดินทาง (แหล่ง: กระทรวงการท่องเที่ยวและกีฬา) ส่วน nomad ใช้จ่ายราว ฿33,000–45,000 ต่อเดือน (model) ทุกเดือนที่เราช่วยให้เขาอยู่ต่ออย่างถูกกฎหมายจึงสร้างเงินเข้าเศรษฐกิจใกล้เคียงนักท่องเที่ยวใหม่ 1 คน และรายได้จาก Local Buddies ก็ตกถึงมือคนไทยในพื้นที่โดยตรง

8. Tech stack และทีม agent

  • Frontend: Astro 7 (static ดีต่อ SEO) + vanilla TypeScript + PWA · ดีไซน์ "Jade & Marigold" ฟอนต์ Anuphan / Sarabun
  • Animation: GSAP ScrollTrigger + three.js · โมเดล 3D (พาสปอร์ต + เกาะไทยลอย) ปั้นใน Blender ผ่าน MCP ขนาด 219 KB
  • Backend: Supabase (Postgres + Auth + RLS ครบ 10 ตาราง) · Stripe Checkout + webhook (test mode)
  • Deploy: Vercel · UX: Miro (sitemap, 3 user flow, wireframe 11 จอ)
  • ทีม: main agent คุมงานและตรวจงาน ส่วน subagent แบ่งตามหน้าที่: UX · UI · Content/Data · DB/Backend · 3D/Motion · Business/Pitch · Frontend A · Frontend B · Home scroll · QA/Deploy · Video

11. ความเสี่ยงและวิธีรับมือ

  • กฎวีซ่าเปลี่ยน: ตรวจกับแหล่งทางการเป็นรอบ แสดงวันที่ตรวจ และระบุข้อมูลที่แหล่งขัดกันให้ผู้ใช้เห็นตรงๆ
  • งานที่กฎหมายควบคุม: ไม่ยื่นวีซ่าเอง ส่งต่อให้ผู้มีใบอนุญาตเท่านั้น และบัดดี้ช่วยได้แค่เรื่องในชีวิตประจำวัน
  • พึ่งพาแพลตฟอร์มอื่น: กระจายรายได้ 3 ขา affiliate มีไม่ถึงหนึ่งในสี่
  • AI แย่ง traffic จาก search: เน้นเครื่องมือและข้อมูลที่ต้องสด ซึ่ง AI ตอบแทนไม่ได้ และสร้าง email list ของตัวเอง
